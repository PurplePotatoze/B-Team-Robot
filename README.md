# B-Team-Robot

This repo contains the CAD files, design, and C++ code for our VEX V5 robotics team. The code used to control our robot includes a tank drive, cascade lift controls, and autonomous controls (for the lift controlls etc.).

## Features
- Tank drive with controller joysticks
- Two-motor cascade lift
- Preset lift positions for picking up and dropping things
- Autonomous and driver control code
- Competition template setup
